# Agenda Marinera

App web (PWA) para iPhone con el horario de la Academia de Dulce Mía Zevallos.
Lee en vivo el Google Sheet "Agenda Mensual Academia 2026" a través de una aplicación web de Apps Script (`Code.gs`).

- Abrir en Safari → Compartir → "Agregar a pantalla de inicio".
- La URL del Apps Script va en `config.js`.
